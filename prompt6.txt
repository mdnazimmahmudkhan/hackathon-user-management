As an admin, I want to search users by name, email, or phone number, so that I can quickly find and manage specific users.

Supporting User Stories

As an admin, I want to search users using a single keyword, so that I don’t need to specify separate fields.

As an admin, I want the search to match:

First name

Last name

Display name

Email

Phone number

As an admin, I want the search to be case-insensitive, so that formatting does not matter.

As an admin, I want to receive paginated results, so that large user lists are manageable.

As an admin, I want inactive or deleted users to be excluded by default, so that I see only valid users.

As an admin, I want to optionally include inactive or deleted users, so that I can audit or restore them.

🧩 Functional Requirements

Accept a search keyword (string)

Search across multiple fields using OR logic

Support pagination (page, size)

Return UserResponse DTOs only

Default behavior:

Exclude deleted users

Exclude inactive users
